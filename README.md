# Pedro Antônio - Portfólio Pessoal

Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades e experiências profissionais e acadêmicas. O site foi construído com tecnologias modernas do ecossistema web para garantir boa performance e um design responsivo.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes ferramentas:

- **[Next.js](https://nextjs.org/)** - Framework React com App Router
- **[React](https://react.dev/)** - Biblioteca UI
- **[Tailwind CSS](https://tailwindcss.com/)** - Estilização utilitária rápida e flexível
- **[Framer Motion](https://www.framer.com/motion/)** - Biblioteca para animações fluidas e complexas
- **[Lenis](https://lenis.studiofreight.com/)** - Scroll suave
- **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática que previne erros
- **[Lucide React](https://lucide.dev/)** - Conjunto de ícones
- **[Vitest](https://vitest.dev/)** - Framework de testes unitários

## ✨ Funcionalidades

- **Design Responsivo:** Adaptado perfeitamente para diferentes tamanhos de tela (mobile, tablet e desktop).
- **Animações Interativas:** Transições suaves, animações de entrada e efeitos de scroll.
- **Projetos e Experiências:** Filtro interativo entre experiências acadêmicas e profissionais.
- **Scroll Suave:** Implementado com Lenis para uma experiência de navegação mais premium.

## 🛠️ Como Executar Localmente

Siga os passos abaixo para rodar o projeto em sua máquina:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Pedroantps/seu-repositorio.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd portfolio
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   # ou yarn install / pnpm install / bun install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   # ou yarn dev / pnpm dev / bun dev
   ```

5. **Acesse a aplicação:**
   Abra o seu navegador e acesse [http://localhost:3000](http://localhost:3000).
